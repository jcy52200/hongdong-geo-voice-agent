# 工作台与 Organic Bento UI

本地首页为 `/#dashboard`。全局导航包括工作台、模拟电话、智能体配置、客户资料、通话记录、系统接入；原来的 `#voice`、`#prompt` 等页面路径保留。语音会话由根组件持有，切换页面不结束正在进行的电话。

## 统计口径

工作台通过 `GET /api/dashboard` 从 SQLite 聚合全部匹配记录，独立于 bootstrap 的最近 10 条限制。没有测试数据填充或虚构涨幅。语音连接统计代表本地 SeedDuplex 联调，当前没有 SIP 外呼，因此没有把这些数字标为真实客户电话接通率。

- 日期：今天、近 7 天、近 30 天；按浏览器本地日历生成包含当天的范围，`from` 包含、`to` 不包含。按会话开始时间筛选。
- 语音连接：只计 `mode=seed`；成功连接依赖 `answeredAt`。连接率为成功数 / 已发起数。较上期为相同长度上一周期的成功数差，使用通数而非虚构增长百分比。
- A/B 对话：按每通电话的等级计数，同一客户多通电话会分别计数。只计最新评估状态为 completed 的结果，重新评估中的旧结果不计入。
- 微信获取率：A 级通话数 / 已完成评估通话数。没有分母时显示“—”。
- 评估进度：已完成评估的通话数 / 已接通且已结束的通话数。连接后异常结束的通话也包含在分母内。
- 客户资料：全量客户库，独立于时间筛选。行业非空且不是“未知 / 待确认 / 未识别”等占位值时计为就绪。头像使用真实客户姓名首字，不生成虚构客户。
- 后台任务：全量行业及分析队列的 pending/running/failed 数量，独立于时间筛选。
- 录音：所选日期范围内实际存有录音元数据的通话数；历史版本没有录音的记录不补造。
- 趋势：按本地日期填齐每日发起与连接次数，零数据不绘制假柱形。

列表最多预览最近 8 通或最近 8 条 A/B 对话。搜索作用于当前预览，完整查询在通话记录页进行；选择记录读取完整对话摘要。点击等级进入通话记录时保留日期范围。待处理任务页提供通向客户、通话和接入页的操作。模型密钥状态仅表示是否配置，不等于实时网络、鉴权或额度检测。

API 参数为 `from`、`to`（带时区的 ISO 时间）、`offsetMinutes`（时区偏移分钟数，默认 480），单次范围上限 93 天。返回周期内统计、上一周期、按日序列、A–G 分布、客户资料就绪情况、最近记录、队列及模型配置状态，不包含密钥。

## 设计与交互

保留现有 React/Vite 和 CSS 组件，使用 `organic.css` 统一主题，不引入另一套完整组件系统。`dashboard.css` 管理工作台布局。色板为浅冷灰蓝 `#F0F4F8`、雾霾蓝、深炭黑 `#22252A`，核心操作使用 `#D4FF33`；意向、告警和错误保留语义颜色。

大卡片使用 24–32 px 圆角，按钮、输入框、导航、状态与选中列表使用胶囊。工作台深色业务区与浅色页签通过径向渐变形成内凹连接。数据可视化使用真实每日微柱、CSS 斜纹进度和有标签的等级分布。

`motion/react` 实现导航与日期胶囊选中背景的共享布局过渡，以及一次性的卡片入场。悬停、按压和表单反馈使用轻量 CSS 过渡；支持 prefers-reduced-motion、prefers-reduced-transparency、键盘焦点和加载/空/错误状态。图标统一为 Phosphor。组件按页面懒加载，配置、记录和工作台分别分包。

窄屏导航可横向滑动，当前项自动进入可见位置；数据卡片、通话列表和详情按断点重排。逐句对话只滚动其自身容器，避免页面切换时被对话滚动抢走视口。
