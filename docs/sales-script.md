# 销售话术与首轮拒绝快速回复

本次话术版本为 `2026-11-02-faq`。实际完整脚本保存在 [prompts/sales-agent.md](../prompts/sales-agent.md)，由服务端构建逐通提示词并随会话保存快照。FAQ 是运营方提供的业务口径，并非项目或模型独立核验的经营事实；脚本保留指定口语回复，同时禁止扩展未提供的保证、资质、数量、价格或合同承诺。

## 对话入口与适用范围

固定首句仍由 AI 主动说出，逐字使用已配置的 opening。播放锁继续等待云端首句音频完成及浏览器实际排空，随后才开放客户输入。快速回复和 FAQ 均不能绕过首句锁。

客户在首轮仅说“不需要”“不想了解”“没兴趣”“暂时不做”等简单拒绝时，先作一次以“那这样老板，我二十秒给您简单介绍下”开头的指定场景介绍，直接带出行业案例和加微信邀请，不先告别或再次询问是否愿意听。客户之后重复明确拒绝，或者明确要求停止、挂断、表示在忙、开会、开车或没时间时，简短收尾。这个分支只争取一次，不循环播放介绍。

FAQ 通过问题的含义适配，不要求逐字匹配，也没有固定提问顺序。客户可在介绍中、报价后或号码确认前插入问题；先回答当前问题，再按微信进度推进。文字规则模拟用于验证有限规则与数据流，不能替代 SeedDuplex 的真实语义理解和声音试听。

| 类型 | 同类问题范围 | 配置回答的重点 |
| --- | --- | --- |
| 高频：首轮拒绝 | 不需要、不想了解、不了解、暂时不做 | 一次行业与本地场景介绍，接案例和微信许可 |
| 高频：服务内容 | 包含什么、发多少、做哪些内容、多少词 | 年包 12800 元；全年累计一万多条内容；3000 多个全维度词汇；新闻、黄页、自媒体、视频 |
| FAQ 1：背景技术 | 哪家公司、服务商、团队、系统、是否靠谱 | 泓动引擎；用户指定的一线服务商、讯灵/摘星及团队经历口径 |
| FAQ 2：停止合作 | 不续费、删除内容、账号和资料归属 | 用户指定的已发布内容、整理资料及客户手机号注册账号归属口径 |
| FAQ 3：内容质量 | AI 写得行不行、要不要招人 | 用户指定的 80 分及专业系统产量、质量比较口径 |
| FAQ 4：配合工作 | 是否托管、需要配人、要做多少事 | 用户指定的一站式托管、3 人团队及资料提供、把关方式 |
| FAQ 5：曝光与数据 | 能否百分之百搜到、怎么查效果 | 确认好的问答词、基本 80% 以上曝光率及数据看板口径，不扩成 100% 保证 |
| FAQ 6：业务解释 | GEO 是什么、不懂 AI、怎么推广 | 从百度搜索转向 AI 提问的场景；图文视频和企业信息呈现 |
| FAQ 7：报价 | 年费、价格、是否额外收费 | 基础版一年 12800 元；未提供的合同和增项细则交人工说明 |
| FAQ 8：效果与时机 | 有无效果、现在做还是以后做 | 用户指定的红利期与案例邀请，不增加确定的涨价日期或新承诺 |
| FAQ 9：价格比较 | 别家便宜、为什么贵 | 使用用户给出的比较话术，不点名断言具体竞品已经违规 |

服务数量属于年包口径，不能直接套到季度或拆成未提供的每月固定交付量。只有客户主动问季度、短期购买或先看效果时，才补充季度 3800 元；季度产品不是免费试用。脚本不自行承诺“绝无其他费用”，具体交付清单、增项与合同条款由人工提供。

行业优先取已补全的 `&industry`；未知时仅从 `&camp` 的明确行业词推断宽泛行业，含混公司名称使用“咱们的产品和服务”。地区只取 `&address` 中可识别的城市或地区，未知时说“咱们当地”，不朗读门牌或变量占位符。

## 微信进度

尚未获得许可时，FAQ 后可自然邀请“加微信发行业案例”；原回复已含邀请时不叠加。已经获得许可就直接确认“您微信电话是我现在打的这个吗”，不再次求许可。不同号则询问微信绑定电话，对收到的新号码逐位读回确认；客户自愿提供微信号时可按字符复核。许可和联系方式均确认后及时收尾，不重复追问，不声称好友已添加或资料已发送。

## 快速回复实现和限制

配置项 `quickReplyEnabled` 默认开启，可在智能体配置页的“首轮拒绝快速回复”中管理。`quickReplyText` 是单独可编辑的快速回复文案，支持 `&industry`、`&address`、`&camp`、`&name`、`&phone` 的单次替换；它与完整限制词中的 FAQ 分别编辑并随新通话保存快照。快速通道只针对开场后的首个最终 ASR 中识别到的简单拒绝，且需满足会话已进入 active、首句锁已释放、麦克风未静音、没有已开始的回复或冲突中的实时控制等条件。输入不完整、意思不明确、已有回复或状态不适合时，安全跳过快速通道，仍由当前系统提示词指导正常模型回应。

该通道使用 [SeedDuplex 官方文档](https://docs.volcengine.com/docs/doubao-voice/end-to-end-real-time-voice-full-duplex-version?lang=zh)中的 `replacement.commit` 回复替换控制，发送已代入行业和地区的指定介绍，省去再次调用大模型选择这段固定话术的步骤。不额外调用 DeepSeek，不使用虚构的延迟或 VAD 参数，不强制提交未完成的音频输入，也不影响首句不可打断。

请求控制并不等于客户已经听到介绍。系统先记录请求审计，`ChatText` 优先取供应商返回文本。官方替代播报也可能只返回音频：只有识别到 `tts_type=chat_tts_text`，且收到相同 `question_id`、非空 `response_id` 的实际音频片段后，才补入未定稿的指定文本；匹配的合成完成事件将它转为定稿，被打断则保持未定稿。迟到的供应商原文会覆盖这条备用文字并复用原行，避免重复。缺少关联标识时不猜测补记。合成完成仍不等于客户听完，实际听到的内容以双向录音为准。最终是否采用、何时发声及效果仍受供应商状态、网络、语音端点检测和播放影响；本地协议测试不构成真实云端毫秒级延迟保证，需要真实通话试听验证。

## 已保存配置和历史会话

服务识别项目已知的旧版默认模板并升级到本次版本，迁移前在 SQLite 设置键 `agent_backup_2026-11-02-faq` 中备份原有配置。音色、开场、语速、其他模型配置及操作员补充要求继续保留。已经保存的自定义完整提示词不会被自动覆盖；需要采用新脚本时，在智能体配置页点击“恢复限制词草稿”得到新草稿，检查后点击保存，新建一通测试。

草稿预览不保存。保存后的配置用于新会话，既有会话的客户资料、初始配置、提示词和哈希快照保持不变。备份不包含对旧通话的重写。操作员补充要求仍参与新会话构建，如有旧的拒绝收尾话术，应在页面检查并更新为当前业务要求。
